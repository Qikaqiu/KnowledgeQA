# KnowledgeQA 产品简介

KnowledgeQA 是一款**私人知识问答库**，帮助个人或小团队把文档整理成可检索、可对话的知识库，并在回答时展示引用来源。

## 产品定位

- 轻量：单仓库 Python 项目，本地几分钟可跑通
- 私有：向量与文档默认存在本机 `data/` 目录
- 多库：不同主题/团队使用独立资料库，互不串答

## 核心能力

### 多资料库管理

- 创建、重命名、删除资料库
- 每个资料库独立文档列表与对话记录
- 演示环境预置：技术文档、产品手册、使用规范

### 文档管理

- 上传 TXT、Markdown、PDF、Word、PPT、Excel 等
- 自动解析、分块、向量化入库
- 点击文件名可查看分块内容；支持下载原文件

### 智能问答

- 基于向量检索 + 大模型生成
- 流式输出，体验接近 ChatGPT
- 每条回答附带引用片段与相关度分数
- 可限定在单个或多个文件范围内提问

### 检索预览

- 不调用大模型，仅展示检索命中与分数构成
- 适合调试问法、验证文档是否被正确索引

## 技术亮点

- 中文嵌入：BGE + FlagEmbedding，检索中文问句更准确
- 混合相关度：语义向量 + 中文关键词，降低「明明文档里有却答不出来」的情况
- 混合模式：演示试用 / 用户自带 Key / 纯检索，一套代码适配多种部署场景

## 适用场景

- 个人笔记与论文资料问答
- 小团队内部技术文档助手
- 产品说明、制度手册的快速查阅
- 开源项目文档的本地 Demo

## 与 AnythingLLM 的关系

本产品借鉴 [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) 的「多工作区 + 文档 RAG」交互思路，但采用更轻的 Python + FastAPI + ChromaDB 栈，适合学习、二次开发和快速私有化部署。
