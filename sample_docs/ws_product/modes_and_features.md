# 运行模式与功能对照

KnowledgeQA 根据 API Key 来源自动切换运行模式，无需用户手动选择「引擎」。

## 三种运行模式

### 完整模式（Full）

**触发条件**：用户在设置中填写并保存自己的 API Key（存于浏览器本地）。

**能力**：
- 完整 LLM 流式对话
- LLM 辅助重排序（提升检索准确度）
- 保存聊天历史
- 批量上传
- 高级设置

**典型配置**：DeepSeek、OpenAI、其他 OpenAI 兼容接口。

### 演示模式（Demo）

**触发条件**：未配置用户 Key，但服务端 `.env` 中设置了 `DEMO_API_KEY`。

**能力**：
- 可用 LLM 流式回答（走服务端 Key）
- 支持检索预览
- 相关度阈值略低于完整模式，便于体验

**限制**：
- 每日提问次数上限（默认 10 次/IP）
- 每分钟次数上限（默认 2 次）
- 单次提问字数上限（默认 500 字）
- 不保存聊天历史到服务端
- 不支持批量上传
- 响应有轻微延迟（`DEMO_DELAY_SECONDS`）

界面会显示「演示模式」标签与剩余次数。

### 检索模式（Retrieval）

**触发条件**：无用户 Key、无演示 Key，且本地 Ollama 不可用。

**能力**：
- 向量检索 + 基于片段的摘要式回答
- 检索预览
- 保存聊天历史

**说明**：适合离线体验检索效果；配置 Key 后可升级为完整或演示模式。

## 模式优先级

```
用户浏览器 Key（完整模式）
    ↓ 无
服务端 DEMO_API_KEY（演示模式）
    ↓ 无
服务端 OPENAI_API_KEY 且 USE_SERVER_API_KEY=true（完整模式，自托管）
    ↓ 无
本地 Ollama 可用（Ollama 模式）
    ↓ 无
检索模式
```

## 功能矩阵

| 功能 | 完整模式 | 演示模式 | 检索模式 |
|------|:--------:|:--------:|:--------:|
| LLM 流式回答 | ✓ | ✓ | 摘要 |
| LLM 重排序 | ✓ | ✗ | ✗ |
| 检索预览 | ✓ | ✓ | ✓ |
| 聊天历史 | ✓ | ✗ | ✓ |
| 批量上传 | ✓ | ✗ | ✓ |
| 引用来源 | ✓ | ✓ | ✓ |

## 常见问题

**问：Embedding 需要联网吗？**  
答：首次需从 Hugging Face 下载 BGE 模型；之后 Embedding 可完全本地运行。

**问：API Key 存在哪里？**  
答：用户 Key 存在浏览器 `localStorage`，请求时通过 `X-User-Api-Key` 头发送，不写入服务端 `.env`。

**问：如何开启演示模式？**  
答：在服务器 `.env` 配置 `DEMO_API_KEY` 后重启；访客打开站点即可看到「免费试用」与演示推荐问题。

**问：支持 PDF 扫描件吗？**  
答：依赖 MarkItDown 提取文本；纯图片扫描 PDF 需 OCR，当前 MVP 未内置 OCR。
